# O3 Mapping Repository #

The current lack of harmonization between data standards for radiation therapy severely limits the ability for data exchange and aggregation among institutions. While creating a barrier to large-scale analysis of patient experiences, this also hampers development and deployment of artificial intelligence tools that can lead to improved patient care. The data standards harmonization project offers a framework for harmonizing existing data standards for radiation therapy with the goal of improving data interoperability for clinical care and cancer research. We have developed a set of data elements common across standards and are currently mapping these elements to the domains and items in existing data standards. These individual mappings will be available as SSSOM TSV files. Eventually, each individual mapping will be combined to create a definitive mapping of all standards to the [Operational Ontology for Oncology (O3)](https://w3id.org/O3_Ontology) to promote an ontology-driven harmonization across the various data standards.

The repository currently holds mappings for:
* common elements to the Clinical Data Interchange Standards Consortium's Study Data Tabulation Model (CDISC SDTM)

Future updates will include mappings for:
* Observational Medial Outcomes Partnership (OMOP)
* Fast Healthcare Interoperability Resources (FHIR)
* North American Association of Central Cancer Registries (NAACCR)
* Operational Ontology for Oncology (O3)
